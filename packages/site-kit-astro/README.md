# @hostsmith/site-kit-astro

An Astro kit for small-business sites, built for sites migrated from Webflow: pages as ordered lists of typed sections in Markdown, a library of section types, the old site's URLs kept exactly, and a GitHub workflow that deploys to [Hostsmith](https://hostsmith.net). The built site is plain static HTML that any host can serve.

A site doesn't install this package on its own: it starts from one of the kit's examples, which wires the package in. See the [kit's README](https://github.com/hostsmith/site-kit-astro#readme) for creating a site, what the package gives a site, and taking kit updates.
