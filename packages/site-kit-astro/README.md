# @hostsmith/site-kit-astro

A reusable kit for building websites with Astro: pages as ordered lists of typed sections in Markdown, a library of section types, header and footer blocks, guidelines for AI agents, URL rules that keep a migrated site's old URLs, and a GitHub workflow that deploys to [Hostsmith](https://hostsmith.net). It ships no CSS: a site takes its design from one of the kit's examples and makes it its own. The built site is plain static HTML that any host can serve.

A new site starts from one of the kit's examples, which wires the package in, and an existing Astro site can add the package's core alone. The [documentation](https://hostsmith.net/docs/site-kit) walks through both, and the [kit's README](https://github.com/hostsmith/site-kit-astro#readme) is the reference: creating a site, what the package gives a site, and taking kit updates.
